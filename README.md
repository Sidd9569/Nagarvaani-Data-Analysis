# Nagarvaani-Data-Analysis

# 🏙️ Nagarvaani

**Nagarvaani** (नगरवाणी) — *Voice of the City* — is a civic issue reporting platform where citizens can report, track, and resolve local infrastructure problems like broken streetlights and electrical faults directly from their mobile devices.

---

## 📊 Data Analysis

Nagarvaani tracks civic complaints through three datasets — **Issues** (ticket ID, type, priority, status, location), **Users** (points, reports submitted, verification), and **Contacts** (support messages). The Power BI dashboard provides real-time visibility into open vs. resolved issues, priority distribution, and user engagement.
